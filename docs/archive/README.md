# Archive

Superseded documents, kept because they carry the reasoning behind decisions
that are still in force. **Nothing in this directory is current state.** Where
an archived document disagrees with `PROGRESS.md` or `HANDOFF.md`, the root
document is right and this one is a snapshot of when it was not.

## What each one was

- **`HANDOFF-2026-08-02.md`** — the original long-form project handoff.
  Superseded on state; still the fullest description of the spacecraft
  systematics that motivate the author-selection check.
- **`CODEX_HANDOFF.md`** / **`CODEX_HANDOFF_2.md`** — the Codex-era handoffs.
  `_2` supersedes the first on state and work queue.
- **`NEXT_AGENT_HANDOFF-2026-08-08.md`** — the P5-entry handoff, written the
  day the seven owner decisions were approved.
- **`EXECUTE_DECISIONS.md`** — the execution plan for those seven decisions,
  approved 2026-08-08 and triggered 2026-08-09. Six of the seven are done;
  decision 6 (shift the science lane to §6.2 monotransits) is the one still
  open. Kept because it records *why* each was approved, which the completed
  work does not.
- **`MILESTONE4.md`**, **`MIGRATION.md`**, **`REFACTOR_REVIEW.md`** —
  completed milestones and a resolved refactor review (zero tracked files
  remaining against it).
